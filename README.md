# M. Sri Hari — 3D Portfolio

## 1. Install
```bash
npm install
```

## 2. Start
```bash
npm run dev
```

Open the local Vite URL shown in the terminal.

## 3. Add your photos
Place your two photos here:

- `public/profile.jpg` — black-and-white seated portrait
- `public/profile-full.jpg` — full-body suit photo

The project visuals in `public/projects/` are original portfolio artwork, not screenshots of the live apps.

## 4. Before deployment
In `src/App.jsx`, replace:
`your-email@example.com`
